# Tetris

Учебный проект игры «Тетрис» на Ruby on Rails, Inertia Rails и React.

## Стек

- Ruby 3.3 и Ruby on Rails 8;
- PostgreSQL;
- Inertia Rails;
- React и TypeScript;
- Vite;
- Tailwind CSS.

Приложение развёрнуто на Render.

## Локальный запуск

Установите Ruby- и JavaScript-зависимости:

```bash
bundle install
npm install
```

Запустите Rails и Vite:

```bash
bin/dev
```

В development-режиме Rails доступен на `http://127.0.0.1:3100`, а Vite запускает свой dev-сервер отдельно.

## Как устроена игра

### Rails и Inertia

`GamesController` создаёт запись игры, передаёт её идентификатор и скорость на React-страницу, принимает выход из игры и сохраняет её итог.

Доступные действия контроллера:

- `index` — выбор скорости;
- `create` — создание записи `Game`;
- `show` — отображение страницы игры через Inertia;
- `quit` — удаление незавершённой игры;
- `finish` — сохранение скорости, количества линий и длительности завершённой игры.

Маршрута и action `step` нет: движение фигуры не отправляется на сервер при каждом нажатии.

### React и игровое состояние

Изменяющееся состояние партии живёт только в браузере. Главный хук [`app/javascript/tetris/useTetrisGame.ts`](app/javascript/tetris/useTetrisGame.ts) создаёт игру, запускает таймер, обрабатывает управление, удаление заполненных строк и завершение игры.

В нём хранится:

- активная фигура;
- зафиксированные клетки поля;
- количество линий;
- состояние завершения игры и анимации очистки;
- состояние ускоренного падения.

Игровая логика расположена в `app/javascript/tetris/`:

- `figures.ts` — создание фигур;
- `move.ts` — перемещение, падение и поворот;
- `collision.ts` — проверка столкновений;
- `field.ts` — поиск и очистка заполненных строк;
- `game.ts` — объединение игровых операций;
- `render.ts` — подготовка поля к отображению;
- `config.ts` — размеры поля и скорость.

Страница игры находится в `app/javascript/pages/Games/Show.tsx`. Поле отображает `components/GameField.tsx`, а мобильные кнопки управления — `components/MobileGameControls.tsx`.

### Управление

Клавиатура и мобильные кнопки используют одну функцию `handleControl` из `useTetrisGame`:

- ← — перемещение влево;
- ↓ — ускоренное падение;
- → — перемещение вправо;
- ↑ — поворот фигуры;
- Escape — выход из игры.

Мобильные кнопки находятся под игровым полем. Они показываются при ширине окна менее `1024px` и скрываются на desktop-размерах классом Tailwind `lg:hidden`.

## Хранение данных

Таблица `games` хранит постоянные данные и итог партии: `speed`, `lines`, `duration`, а также стандартные временные метки. Она не предназначена для хранения текущего положения фигуры или клеток поля.

После окончания игры frontend отправляет итоговые данные в `POST /games/:id/finish`.

## Важное замечание

В `app/services/tetris/` есть ранняя Ruby-реализация классов `Tetris::Field`, `Tetris::Move` и `Tetris::Figure`. Текущая React-игра их не использует. Перед изменением или подключением этих классов нужно сначала проверить цель изменения и влияние на работающую TypeScript-логику.
